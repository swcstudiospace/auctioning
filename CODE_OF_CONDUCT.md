# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep discussion on the work, and
never harass anyone. Race banter about *projects* on the board is the product;
personal attacks on *people* are not.

Reports go to the maintainers via a private GitHub advisory or the contact on
the organisation profile. Reports are handled confidentially.
